# B01 API contract

Base URL: `http://localhost:4000`. Authentication: none. All responses are JSON, include a server-generated `X-Request-ID`, `Cache-Control: no-store`, and `X-Content-Type-Options: nosniff`. HEAD follows Express GET behavior without a response body.

Success: `{"data":{"status":"ok"},"meta":{"requestId":"<uuid>"}}`.
Failure: `{"error":{"code":"NOT_READY","message":"Service is not ready"},"meta":{"requestId":"<uuid>"}}`.

| Request | Body | Status | Result |
| --- | --- | --- | --- |
| GET /health | none | 200 | data.status=ok, independent of DB |
| GET /ready | none | 200 | data.status=ready, MySQL query succeeds |
| GET /ready | none | 503 | NOT_READY, MySQL query fails |
| GET /api/v1/missing | none | 404 | NOT_FOUND / Route not found |
| POST /api/v1/missing | `{` with application/json | 400 | INVALID_JSON / Invalid JSON body |
| Any JSON request over 16 KB | oversized JSON | 413 | BODY_TOO_LARGE / Request body too large |
| Unexpected internal failure | any | 500 | INTERNAL_ERROR / An unexpected error occurred |

Business API prefix is `/api/v1`; no business endpoints exist in B01. Root probe paths match the proposal, so no route change needs approval. Request IDs are not client-controlled. Error responses omit raw exception messages, stacks, SQL and credentials. Unsupported paths/methods return 404. No authorization assertions apply until protected endpoints exist.
